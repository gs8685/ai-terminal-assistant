Why Use CLI Agent?

Stop context switching between browsers, IDEs, and manual documentation. CLI Agent provides a multi-agent pair programmer directly inside your terminal session.

🧠

Two-Agent Sequential Pipeline

Powered by CrewAI, a Router Agent first classifies intent into Shell, File, Code, or Git and structures a plan. An Executor Agent carries out the operations safely.

🏎️

Fast-Path Execution Engine

Detects direct CLI commands (e.g. git status, ls -la) and executes them in <50ms without wasting LLM token credits or incurring API latency.

⚡

Zero-Dependency Executables

Compiled standalone binary executables (Windows, macOS, Linux) mean your team can run CLI Agent instantly without needing Python or pip installed.

How CLI Agent Helps You Debug

Built-in safeguards prevent token bloat, catch syntax errors early, and expose live telemetry.

01. AST Bytecode Syntax Checking

Catch Syntax Errors Pre-Execution

When using code_tool with check_syntax, CLI Agent runs Python's native py_compile bytecode parser. Syntax errors are caught immediately with line numbers before bad edits touch your filesystem.

02. Zero Context Window Bloat

Line Filtering & 500-Line Capping

When running recursive shell commands (like dir /s), filter_shell_output() strips out all venv, __pycache__, and node_modules lines and caps output to 500 lines max (~15,000 tokens), preventing HTTP 500 crashes.

03. Git Diff & Commit Troubleshooting

Plain-English Failure Diagnosis

Diagnose uncommitted code breakages by asking "check git diff and explain why the build failed". CLI Agent inspects uncommitted changes and recent commit logs to report precise code fixes.

04. Collapsible Debug Drawer (Ctrl+D)

Live TUI Telemetry & Event Tracing

Press Ctrl+D inside the Textual TUI at any time to open the live telemetry log drawer. View real-time LLM API calls, router decisions, and tool parameters while the screen stays clean.

Security & Hardened Guardrails

Enterprise-grade safety features designed to protect your workstation and API credits.

Guardrail Feature Enforcement Mechanism Developer Protection Outcome
Deep Path Inspector is_ignored_path() checking path segments Silently skips .venv, venv, node_modules, .git, __pycache__.
File Size Limit Cap max_bytes = 200 * 1024 (200 KB max) Prevents single file reads from overfilling LLM context windows.
Shell Output Filter filter_shell_output() 500-line cap Caps shell command output to top 500 lines (~15,000 tokens max).
Sensitive File Blocklist Cross-platform path blocklist check Proactively blocks /etc/shadow, ~/.ssh/id_rsa, SAM, .aws/credentials.
Execution Timeout max_execution_time = 300 seconds Allows deep project analysis while preventing infinite execution loops.
